Muse Windows 安装与浏览器采集说明
================================

一、安装 Muse（推荐）

1. 双击“01-Muse-安装版.exe”。
2. 按安装向导完成安装，桌面会创建 Muse 快捷方式。
3. 第一次打开 Muse 时，选择或创建你的 Muse Library 位置。

如果 Windows SmartScreen 提示“Windows 已保护你的电脑”，这是因为当前测试版尚未购买公开代码签名证书。请确认文件来自可信的分享者，然后选择“更多信息”→“仍要运行”。

二、安装 Chrome / Edge 浏览器扩展

Chrome：
1. 地址栏打开 chrome://extensions
2. 打开右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择分享包里的“02-浏览器扩展”文件夹

Edge：
1. 地址栏打开 edge://extensions
2. 打开“开发人员模式”
3. 点击“加载解压缩的扩展”
4. 选择分享包里的“02-浏览器扩展”文件夹

三、连接与采集

1. 先打开 Muse。
2. 点击浏览器工具栏中的 Muse 扩展图标，然后点击“重新连接”。
3. Muse 弹出配对请求时选择“允许”。
4. 在普通网页图片上点击右键，选择“保存到 Muse”。

四、免安装版本（可选）

“03-Muse-免安装版.exe”可直接运行，适合临时体验。不要同时运行安装版和免安装版。

五、说明

- 浏览器采集只在用户主动右键时工作，不读取浏览历史或 Cookie。
- 某些必须登录、必须依赖网页 Cookie 才能下载的图片，当前版本可能无法采集。
- 网页返回静态 WebP 时，Muse 会保存为兼容性更好的 JPG；透明图片保存为 PNG。
- Muse 的 Library 数据保存在用户自己选择的位置，不包含在本分享包里。
