## 根据真实结果完成的调优

Prompt 从 v1.1 升至 `codex-batch-v1.2`，但遵守“completed 不重复分析”，没有为了美化报告重新消耗这 20 张：

1. 明确 Primary 为广义主题域、Secondary 为媒介或受控类别、Tertiary 为具体子类型，修复 7/8/9/11 中出现的层级顺序漂移。
2. 明确 .95–1.00 只用于直接可见且无歧义的事实；Style、Mood、Material、Usage 通常应低于 .95。
3. `overallConfidence` 必须反映最不确定的重要维度，不再简单复制对象字段的最高置信度。
4. 保持现有 Controlled Vocabulary；开放对象、材质和颜色继续进行中文 trim、normalize 和去重，不针对文件名写规则。

## 结论

内容、对象、场景、风格、语义颜色和描述均来自 Codex 对真实
`localImage` 的视觉判断，没有 mock 或文件名硬编码。总体识别质量可用于
Inspector、普通搜索和 Smart Collection；下一轮最值得继续观察的是跨批次
Category 层级一致性、解释性字段的置信度校准，以及边界场景词的保守程度。
