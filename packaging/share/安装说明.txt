Muse 0.1.0 Windows 内测版
=========================

一、安装 Muse

1. 双击“1-安装Muse\Muse-Setup-0.1.0-x64.exe”。
2. 如果 Windows SmartScreen 提示未知发布者，请确认文件来自分享者后，选择“更多信息”→“仍要运行”。
3. 安装完成后启动 Muse，并至少打开一次主界面。

二、安装 Chrome 扩展

1. 在 Chrome 地址栏输入：chrome://extensions
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择分享包中的“2-浏览器扩展\Muse-Web-Collector”文件夹。
5. 确认扩展名称为“Muse Web Collector”，版本为 0.2.1。
6. 点击浏览器工具栏中的 Muse 图标，应显示“已连接”。

三、安装 Edge 扩展

1. 在 Edge 地址栏输入：edge://extensions
2. 打开“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择“2-浏览器扩展\Muse-Web-Collector”文件夹。
5. 确认版本为 0.2.1，并检查扩展显示“已连接”。

四、保存网页图片

1. 在普通网页图片上点击鼠标右键。
2. 选择“保存到 Muse”。
3. 出现“已保存到 Muse”后，图片会进入 Muse 素材库。
4. 同一图片再次收藏不会重复创建文件；从其他网页收藏同一图片时，会为原素材增加来源记录。

五、注意事项

1. 网页采集不会读取浏览器 Cookie 或浏览历史。
2. 需要登录 Cookie 才能访问的图片，当前版本可能无法保存。
3. 网页采集默认不会调用 Codex；是否自动分析遵循 Muse 内的现有设置。
4. 图片保存后，本地颜色与视觉/语义索引会在后台生成。
5. 不要移动或删除扩展文件夹，否则 Chrome/Edge 无法继续加载扩展。

六、连接问题

1. 先完全退出 Muse，再重新启动 Muse。
2. 在扩展管理页确认版本为 0.2.1，并点击一次“重新加载”。
3. 如果仍未连接，完全退出 Chrome/Edge 后重新打开。
4. 仍然失败时，请把扩展弹窗和 Muse 错误提示截图发给软件提供者。

用户素材默认保存在用户自己选择的 Muse Library 中。升级或重新安装前请保留素材库目录。
